# Study Dashboard

## Project Description

The Study Dashboard is a Python-based prototype designed to help students organize and monitor their academic progress.

## Main Features

- Study progress overview
- Weekly learning goals
- Learning hours tracking
- Exam and grade overview
- Learning focus indicators
- Personal notes with add and edit functions
- Theme selection
- Automatic data saving

## Technologies Used

- Python
- Tkinter
- JSON
- Visual Studio Code

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```
